# THIRD_PARTY.md — licence ledger

Every dependency, reference and asset is listed here. **Nothing from the
commercial game (Among Us / Innersloth) is used: no art, audio, fonts, map
layout, character design, names or code.** "AImong Us" is a private working title
for a friends-only build.

## 5. Provider terms (services, not assets)

LLM calls go to OpenRouter / NVIDIA NIM / Groq under the owner's own accounts and
their terms. The free NVIDIA tier is documented for testing/evaluation, which
matches this private build. No user content is sent anywhere except the in-game
observations of AI seats.
