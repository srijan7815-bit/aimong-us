# M3.5 — full role and feature set (report)

Date: 2026-11-01 · Milestone status: **complete, pushed, verified live**
Version: `0.5.0` · `MILESTONE = 'M3.5'`

M3.5 is the scope expansion the owner asked for: every role and in-game feature of
the genre must exist, with **original** names, art and wording. This milestone
implements Tier 1 (crew/impostor + Patch, Watcher, Warden, Shifter; the full
meeting/voting rule set; task categories and stages; map tools; five sabotages;
the settings a host needs; free-roam practice, quick chat, cosmetics).

> Everything below is mechanics-only. No asset, name or string is taken from a
> commercial game: the roles are Patch (vent-using crew), Watcher (handheld
> vitals), Warden (post-mortem shield) and Shifter (disguise impostor). Original
> names, original art (drawn in code), our own numbers. See `THIRD_PARTY.md`.

## Bugs found and fixed while testing

1. **Scripted walking shuttled in place.** Aiming at the *next* A* node makes a
   walker turn around the moment it drifts past that node's centre. Fixed in
   `steerAlongPath` (shared): skip nodes already reached, aim up to 3 ahead, and
   only cut a corner when the straight line to the target node is clear.
2. **Each new walk restarted the input sequence at 1,** and the server drops
   packets older than the last one it saw — so every leg began with ~1.5 s of
   standing still, and long legs timed out. Sequence numbers are now per seat for
   the whole match.
3. **O2 could not be fixed in time** in the test because one pod walked to both
   consoles; both fixers now walk at once.
4. **The Warden's 10 s ward expired** while the killer crossed the station; the
   test now positions first and wards second. (A real design note too: the ward is
   short on purpose — it is a reaction, not a bubble.)
5. **The Render build failed twice on the lockfile.** `ERR_PNPM_FROZEN_LOCKFILE_WITH_OUTDATED_LOCKFILE`:
   pnpm 12 (which the build installs) refuses a lockfile that does not record its
   own `packageManagerDependencies`, and a plain `pnpm add playwright` in this
   sandbox rewrote the lockfile with pnpm 9's format. The committed lockfile is
   now pnpm 12.16.1's own output and Playwright is not a repo dependency
   (`DECISIONS.md` 26). Reproduced and verified in a clean clone before pushing.
6. **Lobby chat was refused.** The new `say()` router treated "not in a meeting"
   as "no chat", which broke lobby chat — the smoke test caught it. Lobby and
   results screens now have open chat.
7. **The host's role chances leaked into a leak check.** Settings are public by
   design (`engineerChance` is not a secret); the check now inspects player rows
   only.

## Honest gaps

- Tier 2 (Noisemaker, Tracker, Phantom, a detective role, a second map with
  ladders/moving platforms, map selection) is **not** in this build; it is
  scheduled before M7 as agreed.
- Bots are still bodies that stand still — the abilities exist in the shared
  tables that M4's scripted bodies and M5's prompts will read, but no AI uses them
  yet. Nothing on screen claims otherwise.
- Cosmetics are a simple overlay system (no shop, no unlocks); pets do not follow
  with path-finding, they trail the pod.
- The door log and cameras are text panels, not a camera feed with a moving
  picture.
